# WayFinders

Редактор графа улично-дорожной сети на основе OpenStreetMap. Открывает `.osm`, показывает дороги в 2D и 3D, дает править граф, находит ошибки и сохраняет `.osm`, который проходит MatSim, SUMO и Webots.

Международный урбанистический хакатон «Транспортное планирование городов», Иркутск, ИРНИТУ, ноябрь 2026.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run build
npm start
```

Режим разработки (изменения в коде видны сразу):

```bash
npm run dev
```

Сборка исполняемого файла (папка `release/`):

```bash
npm run dist
```

Для Windows (portable .exe) лучше собирать на Windows:

```bash
npm run dist:win
```

## Что умеет версия 0.1

- **Открытие:** файл `.osm`, встроенный пример `example.osm` (участок Иркутска от организаторов), загрузка любого района или города из OpenStreetMap через Overpass API.
- **Карта:** дороги по классам, толщина по числу полос, стрелки направлений, здания (в 3D объемные), мосты подняты над землей, подложка схема или спутник, поиск улицы.
- **Правка:** выбор и перенос узлов, рисование дороги по шаблону, разрезание, удаление, разворот направления; класс, направление, полосы, скорость, покрытие, мост или тоннель, любые теги OSM; отмена и повтор.
- **Светофоры:** учитываются только светофоры на проезжей части (железнодорожные сигналы и светофоры вне дорог не считаются). Для светофора задается время: цикл, зеленый, желтый, красный.
- **Проверки:** разорванные перекрестки, пересечения без узла, изолированные участки, ловушки по направлениям (сильная связность), пустые атрибуты, мосты без `layer`. Исправление в один клик.
- **Расчеты:** V своб = maxspeed × коэффициент покрытия; T своб = L / V своб считается отдельно; Z = N / P, V ср, q, T зад, D. Графики, выгрузка в CSV и PNG, редактируемые нормативы.
- **История и сравнение:** журнал правок, сравнение с исходным файлом, выгрузка в CSV.
- **Сохранение:** проверка перед записью, новые элементы получают положительные id, все остальные объекты карты сохраняются без изменений.

## Свои теги в .osm

В OSM нет стандартных тегов для этих данных, поэтому редактор хранит их в пространстве `wayfinders:`. Симуляторы такие теги пропускают.

| Тег | Где | Что значит |
|---|---|---|
| `wayfinders:cycle`, `wayfinders:green`, `wayfinders:yellow`, `wayfinders:red` | узел-светофор | время фаз, секунды |
| `wayfinders:volume` | дорога | интенсивность N, авт/ч (замер) |
| `wayfinders:travel_time` | дорога | фактическое время проезда T факт, мин (замер) |
