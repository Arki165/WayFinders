# Wayfinder

Программа команды WayFinders. Редактор графа улично-дорожной сети на основе OpenStreetMap.

Международный урбанистический хакатон «Транспортное планирование городов», Иркутск, ИРНИТУ, ноябрь 2026.

Wayfinder открывает файл `.osm`, показывает дороги на карте в 2D и 3D, дает править граф, сам находит ошибки и сохраняет `.osm`, который проходят симуляторы MatSim, SUMO и Webots. Кроме графа программа выгружает файлы для сервера проверки (фазы светофоров для SUMO, высоты мостов для Webots), считает загрузку дорог по нормативам и читает результаты прогона SUMO.

## Быстрый старт

### Готовая программа

- **Windows:** переносимый `Wayfinder <версия>.exe` (x64). Установка не нужна, файл запускается двойным кликом. Windows может показать предупреждение SmartScreen, потому что файл без цифровой подписи: «Подробнее» → «Выполнить в любом случае».
- **macOS:** установщик `.dmg`.

Готовые файлы выкладываются в раздел **Releases** на GitHub.

### Запуск для жюри

**Windows.** Скачайте из Releases архив `Wayfinder-<версия>-win.zip` и распакуйте в любую папку. В архиве:

- `Wayfinder <версия>.exe` - программа, ничего устанавливать не нужно;
- `demo/hack-team3.osm` - граф после редактора, который команда отправила на сервер проверки;
- `demo/Wayfinders_demo.osm` - тот же участок с замерами для картограммы и расчетов;
- `ЗАПУСК.txt` - эта же инструкция коротко.

Запустите `.exe` двойным щелчком. На окно «Система Windows защитила ваш компьютер» нажмите «Подробнее», затем «Выполнить в любом случае». Первый запуск занимает 10-20 секунд: программа распаковывает себя во временную папку. Затем «Открыть пример: Иркутск, example.osm» (файл организаторов уже внутри программы) или «Открыть» и файл из папки `demo`.

**macOS** (Mac с процессором Apple M1-M4). Скачайте `.dmg`, откройте и перетащите Wayfinder в «Программы». Файл без подписи Apple, поэтому при первом запуске нажмите на программу правой кнопкой, «Открыть», затем еще раз «Открыть» (или «Системные настройки» → «Конфиденциальность и безопасность» → «Все равно открыть»). Если macOS пишет, что программа повреждена, выполните в Терминале `xattr -cr /Applications/Wayfinder.app`.

**Что нужно компьютеру:** Windows 10/11 64 бит или macOS на Apple M1-M4, видеокарта с WebGL 2 (если карта не рисуется, обновите драйвер). Интернет нужен только для подложки (спутник, схема), рельефа в 3D и загрузки района из OpenStreetMap: без интернета граф открывается, правится, проверяется и сохраняется. Свои настройки программа хранит в `%APPDATA%WayFinders` (Windows), удалить программу - удалить файл.

Нужен Node.js 20 или новее.

```bash
npm install
npm run build
npm start
```

Режим разработки (изменения в коде видны сразу):

```bash
npm run dev
```

Сборка исполняемого файла в папку `release/`:

```bash
npm run dist
```

Переносимый `.exe` для Windows:

```bash
npm run dist:win
```

На macOS с процессором Apple `.exe` для обычных компьютеров с Windows собирается с ключом x64:

```bash
npx electron-builder --win portable --x64
```

## Типовая работа

1. Открыть граф: свой файл, пример Иркутска или загрузка района из OpenStreetMap.
2. Посмотреть вкладку «Ошибки» и исправить критичные ошибки.
3. Поправить дороги: полосы, направления, скорости, покрытие, светофоры, переходы, мосты.
4. Задать замеры (или загрузить результаты SUMO) и посмотреть загрузку сети.
5. Сохранить `.osm`.
6. Выгрузить файлы для сервера: фазы светофоров и высоты мостов.
7. Отправить на сервер проверки, после прогона загрузить `fcd.xml` обратно в программу.

| Слева | инструменты правки и выключатель магнита |

| Снизу | вкладки «Расчеты и графики», «Сравнение с исходным», «Формулы» |

Правую и нижнюю панель можно растянуть мышкой за край и скрыть кнопкой со стрелкой. Раскладка окна запоминается.

Меню в правом углу верхней панели: тема (светлая или темная), язык (русский или английский), руководство пользователя, список горячих клавиш.

Руководство пользователя встроено в программу: меню → «Руководство».

## Как открыть граф

- **Открыть** (Ctrl+O): файл `.osm` с диска.
- **Пример**: участок Иркутска от организаторов (`example.osm`), кнопка на стартовом экране.
- **Из OSM**: загрузка из OpenStreetMap через Overpass API.
  - «Скачать видимую область карты»: то, что сейчас на экране.
  - «Скачать город»: по названию, по-русски или по-английски. Если городов с таким названием несколько, программа покажет список со страной и населением.
  - Галочка «Вместе со зданиями» нужна для 3D и Webots.
  - Крупный город (больше 1,5 млн жителей) скачивается кусками, это несколько минут. Кнопка «Отмена» работает в любой момент.
- **Добавить карту**: присоединить еще один `.osm` или район к уже открытой карте. Одинаковые дороги не дублируются, дороги на стыке сшиваются.

Если в открытом графе есть несохраненные правки, программа спросит подтверждение перед тем, как открыть другой.

Программа не привязана к Иркутску: любой город загружается из OpenStreetMap и правится так же.

## Карта

- Колесо мыши: масштаб. Перетаскивание: сдвиг.
- **2D / 3D** (клавиша 3): вид сверху или наклонный вид с объемными зданиями и поднятыми мостами.
- **Подложка**: схема или спутник.
- **Слои** (кнопка на карте справа):
  - уровень «Город» или «Метро»;
  - включение дорог, полос, светофоров, переходов, остановок, метро, железной дороги, тротуаров и ошибок;
  - ползунок яркости подложки: влево остается только граф.
- **Поиск** (Ctrl+F): улица, остановка или номер дороги. Улица выделяется целиком.
- **Весь граф**: кнопка на карте, возвращает вид на весь граф.
- При сильном отдалении карта становится глобусом, внизу появляется кнопка «Вернуться к графу». Дальше линейки около 2000 км карта не отдаляется.

Что видно на разных масштабах:

| Масштаб | Что появляется |
|---|---|
| Город целиком | дороги цветом по классу, толщина по числу полос |
| Около 500 м | круги ошибок |
| Около 100 м | полосы, разметка, значки светофоров, переходов и остановок |
| Около 50 м | асфальт с белой разметкой, стрелки поворотов, «зебры», стоп-линии |

## Инструменты правки

| Клавиша | Инструмент | Что делает |
|---|---|---|
| V | Выбор | клик выделяет дорогу, полосу или узел. Узел можно перетащить |
| W | Нарисовать | новая дорога по точкам. Enter или двойной клик: готово, Esc: отмена |
| N | Добавить узел | клик по линии дороги ставит на нее узел |
| J | Соединить | узел с узлом или с дорогой |
| U | Разъединить | у каждой дороги в этом месте будет свой узел |
| X | Разрезать | клик по среднему узлу делит дорогу на две |
| T | Светофор | клик по узлу ставит или убирает светофор |
| D | Удалить | клик по дороге или узлу |
| M | Магнит | включает и выключает прилипание точек |

Выделение нескольких дорог: Shift+клик. Участок между двумя узлами: клик по первому узлу, Shift+клик по второму. Изменения применяются только к участку, дороги по краям разрежутся сами.

### Рисование дороги

1. Нажать W. Над картой появится панель рисования.
2. Выбрать шаблон. Шаблоны показаны карточками: рисунок поперечного профиля, число полос, ширина проезжей части, скорость. Кроме дорог есть тротуар, пешеходная дорожка, трамвайные пути, железная дорога и здание.
3. Кликать точки. У курсора видна длина отрезка и угол поворота.
4. Режим «Дуга»: новая точка соединяется с предыдущей дугой, которая плавно продолжает прошлый отрезок. В подписи виден радиус. Так рисуют повороты без острых изломов.
5. «Магнит»: точка прилипает к ближнему узлу или встает на линию дороги общим узлом. Зеленый кружок показывает, куда она прилипнет.

Магнит работает и при правке: если потянуть узел дороги к другому узлу или к линии другой дороги, он прилипнет, а после отпускания соединится с ней. Перенос и соединение отменяются одним Ctrl+Z.

Дорогу нельзя провести сквозь здание: программа не поставит точку и объяснит почему. Мост, тоннель и проезд под домом разрешены.

## Свойства дороги и полос

Выделите дорогу, справа откроется вкладка «Свойства».

- **Название.** На английском языке правится английское название.
- **Класс дороги.** Улицы города (по СП 42.13330) или категория дороги общего пользования IА-V (по ГОСТ Р 52398).
- **Направление.** В обе стороны, туда или обратно. Клавиша R разворачивает направление.
- **Полосы.** Кнопки «Меньше полос» и «Больше полос», схема полос.
- **Скорость и покрытие.** Покрытие задает коэффициент сцепления φ, от него зависит свободная скорость. У дороги можно задать свое φ, например для зимы или мокрого покрытия.
- **Искусственные сооружения.** Нет, мост или тоннель.
- **Автобусная полоса.** Нет, справа, с двух сторон.
- **Трамвай по дороге.** Пути по проезжей части.
- **Замеры.** Интенсивность N (авт/ч) и фактическое время проезда T факт (мин).
- **Расчет.** Пропускная способность P, загрузка Z, кнопка «Добавить в расчет».

### Полосы по отдельности

Кликните полосу на карте или на схеме в панели. У полосы меняются:

- направление;
- повороты: налево, прямо, направо, разворот;
- разметка слева и справа: сплошная или прерывистая;
- тип: общая, автобусная, велосипедная;
- своя скорость и ширина.

Полосы записываются стандартными тегами OSM (`lanes`, `turn:lanes`, `change:lanes`, `width:lanes` и другие), поэтому их понимает SUMO.

## Узлы, перекрестки, светофоры

Выделите узел. В панели видны дороги через узел и действия.

- **Светофор:** время цикла, зеленый, желтый, красный. Фазы общие или свои для каждого подхода со сдвигом. Кнопки «Поочередно 60/90 с» заполняют типовой режим. Учитываются только светофоры на проезжей части: железнодорожные сигналы и светофоры вне дорог не считаются.
- **Пешеходный переход:** через какую дорогу, регулируемый или нет.
- **Кольцо:** перекресток заменяется круговым движением радиусом 18 м.
- **Разворот 180°** и **поворот 90°:** шаблоны-вставки.
- **Мост над пересечением:** участок дороги становится мостом.
- **Связи полос:** если выбрать узел перекрестка вблизи, на карте видны линии, с какой полосы на какую можно проехать. Оранжевые: налево, бирюзовые: прямо, зеленые: направо. Связи меняются стрелками поворота в свойствах полосы.

У светофоров на карте рисуются стоп-линии.

## Ошибки графа

Вкладка «Ошибки» справа. Проверка идет сама после каждой правки. У каждой ошибки есть кнопки «Показать», «Исправить» и «Пропустить».

| Ошибка | Что значит | Исправление |
|---|---|---|
| Разорванный перекресток | конец дороги ближе 12 м к другой дороге, но не соединен | «Соединить» |
| Пересечение без узла | дороги пересекаются на одном уровне без общего узла | «Добавить узел» |
| Изолированный участок | кусок сети не связан с остальной | «Удалить» |
| Ловушка по направлениям | въехать можно, а выехать нельзя, или наоборот | поправить направления вручную |
| Не заполнены атрибуты | у крупной улицы нет числа полос или скорости | «Заполнить» |
| Мост без уровня | мост может склеиться с дорогой под ним | «Поднять мост» |
| Дорога сквозь здание | в Webots машина проедет через стену | «Мост над зданием» |
| Длинный участок без перекрестков | предупреждение, порог зависит от класса | соединить с соседними или оставить |
| Значение не поймут симуляторы | например, `lanes=много` | «Убрать значение» |
| Отрезок нулевой длины | два соседних узла в одной точке | «Слить узлы» |

Цвета: красные - критичные, оранжевые - предупреждения, синие - подсказки.

Кнопка «Соединить все разрывы» чинит все разорванные перекрестки сразу. Это одна правка, отменяется одним Ctrl+Z.

Вверху вкладки показана связность по направлениям: доля узлов, из которых можно доехать до любого другого (сильная связность, алгоритм Тарьяна). Для симуляции нужно близко к 100%. Дороги, обрезанные краем скачанной области, снижают эту цифру, и это нормально.

## Расчеты и загрузка

### Таблица и графики

Нижняя вкладка «Расчеты и графики».

1. Выделить дорогу или несколько и нажать «+ Выделенная». Или «Все крупные улицы».
2. Вписать замеры N и T факт прямо в таблицу или загрузить их из прогона SUMO (кнопка «Из прогона SUMO...», см. ниже).
3. В таблице по каждому участку: длина L, V max, φ, V своб, T своб, полосы, P, N, T факт, загрузка Z, V ср, плотность q, задержка T зад и D.
4. График строится по участкам из таблицы: загрузка Z, время, скорость. В списке «Диаграммы потока» есть N(q), V(q), D(Z), V(N), D(q) и задержка в течение суток.
5. Выгрузка: таблица в CSV и Excel, график в PNG, Excel и PDF.

Формулы:

| Величина | Формула |
|---|---|
| V своб | V max · √(φ / 0,8), при φ ≥ 0,8 скорость не снижается |
| T своб | L / V своб |
| P | число полос · пропускная способность полосы для класса дороги |
| Z | N / P |
| V ср | L / T факт |
| q | N / V ср |
| T зад | T факт - T своб |
| D | T зад / T своб · 100% |

Нормативы (пропускная способность полосы по классам, коэффициенты сцепления φ по покрытиям, пороги Z) меняются кнопкой «Нормативы» и применяются сразу. Подробно каждая величина расписана на вкладке «Формулы».

Уровни загрузки по Z: свободно, умеренно, загружено, перегружено.

### Загрузка результатов SUMO

Кнопка «Из прогона SUMO...» на вкладке «Расчеты и графики». Выберите `fcd.xml`, который сервер проверки отдает после прогона. В нем каждую секунду записано, где едет каждая машина и с какой скоростью.

По каждой дороге, где ехали машины, программа запишет:

- **N:** сколько разных машин проехало по дороге за час симуляции;
- **T факт:** длина дороги, деленная на среднюю скорость машин на ней (стоянка в пробке тоже учитывается).

Эти дороги сразу добавляются в таблицу, дальше все считается как с ручными замерами. Загрузка отменяется одним Ctrl+Z. `fcd.xml` должен быть от прогона этого же графа.

### Картограмма загрузки

Кнопка «Загрузка Z» (клавиша H).

- Цвет дороги по Z: зеленый - свободно, желто-зеленый - умеренно, оранжевый - загружено, красный - перегружено. Серый - замера нет.
- Ширина полосы поверх дороги показывает интенсивность N.
- В середине дороги плашка со значением Z.
- Внизу карты легенда с порогами и числом дорог с замером.

Картограмма строится только по дорогам, у которых задана интенсивность N.

## Маршруты и остановки

Вкладка «Маршруты» справа.

- Список маршрутов из файла: автобус, троллейбус, трамвай, маршрутка. Поиск по номеру и остановке.
- Клик по маршруту рисует его на карте цветной линией с пронумерованными остановками. В карточке длина и список остановок. Куски маршрута, которых нет в файле (короткие пропуски в данных OSM), достраиваются на карте по дорогам или трамвайным путям, только для показа.
- **Свой маршрут:** кнопка «Свой маршрут», выбрать вид транспорта и номер, потом кликать дороги и остановки на карте. Повторный клик убирает. Начало и конец - первая и последняя остановка.
- **Новая остановка:** в правке маршрута поле «Новая остановка» и кнопка «Поставить на карте». Клик по карте ставит остановку и добавляет ее в конец маршрута.
- **Правка остановки** в панели «Свойства»: название и вид транспорта. Отдельную точку можно сделать остановкой.
- Любой маршрут можно изменить кнопкой с карандашом, свой - удалить.

У выбранной остановки рисуется круг пешей доступности: 350 м для автобуса и троллейбуса, 500 м для трамвая. В панели видны маршруты через остановку.

## Здания

Кнопка «Здания» в верхней панели показывает их на карте, в 3D они объемные.

- Новое здание: инструмент «Нарисовать», шаблон «Здание», кликать углы.
- Выбранное здание можно перенести целиком, двигать углы, добавить угол на стене (потянуть за стену) и убрать угол (Shift+клик).
- В панели: этажность, высота, площадь застройки, кнопка «Убрать лишние углы».
- Здание нельзя поставить на дорогу.

## История и сравнение

- Вкладка «История»: журнал всех правок. Любую правку можно отменить (Ctrl+Z) и вернуть (Ctrl+Y), включая массовые.
- Нижняя вкладка «Сравнение с исходным»: таблица «было и стало» и список измененных дорог, выгрузка в CSV.
- Кнопка «Правки» в верхней панели подсвечивает на карте новые, измененные и удаленные дороги.

## Сохранение

Кнопка «Сохранить» (Ctrl+S) открывает окно с проверкой:

- сколько критичных ошибок и предупреждений;
- связность по направлениям;
- сколько новых элементов получат положительные id.

Дальше «Перезаписать» или «Сохранить как». Здания, остановки, маршруты, запреты поворотов и все остальные объекты карты сохраняются без изменений. Если файл не записался, программа скажет об этом.

Точка рядом с именем файла в верхней панели означает несохраненные правки.

Сервер проверки принимает файл с именем команды: команда `team1` отправляет `team1.osm`.

## Файлы для сервера проверки

Сервер прогоняет граф по цепочке MatSim → SUMO → Webots и отдает три видео, `pipeline.log`, `scenario.zip`, `fcd.xml` и `webots.wbt`. Кроме графа, на сервер можно загрузить необязательные файлы. Два из них делает Wayfinder, обе кнопки в окне сохранения.

| Файл | Поле на сервере | Кнопка | Откуда данные |
|---|---|---|---|
| `<команда>.osm` | граф | «Сохранить» | граф из редактора |
| `additional.add.xml` | расписание фаз светофоров | «Фазы светофоров...» | время фаз из редактора + `network.net.xml` прошлого прогона |
| `elevation.xml` | высоты дорог Webots | «Высоты мостов...» | мосты графа (`bridge`, `layer`) |

### Фазы светофоров для SUMO

SUMO не читает время фаз из `.osm` и ставит светофорам свое время по умолчанию. Поэтому время из редактора отдается отдельным файлом.

1. Сделать один прогон графа на сервере и скачать `scenario.zip`.
2. В окне сохранения нажать «Фазы светофоров...» и выбрать `network.net.xml` из этого архива.
3. Программа берет из сети схему сигналов каждого светофора и подставляет длительности фаз из редактора. Получается `additional.add.xml` с программой `wayfinder`, которую SUMO загружает поверх стандартной.
4. Загрузить `additional.add.xml` на сервер вместе с графом. В логе появится строка «Принят additional.add.xml».

Если перекрестки в графе менялись, файл фаз нужно выгрузить заново по сети нового прогона.

### Высоты мостов для Webots

Кнопка «Высоты мостов...» пишет `elevation.xml`. Рельеф не учитывается, все дороги остаются на нуле, поднимаются только мосты: 5 м за каждый уровень `layer`, плавный въезд 40 м, под мостом опоры. Формат:

```xml
<elevation>
<road way="81608266" height="5" ramp="40" supports="true"/>
</elevation>
```

`way` - id дороги OSM, `height` - высота в метрах, `ramp` - длина плавного подъема в метрах, `supports` - ставить ли опоры. В логе Webots появится строка «Принят elevation.xml» и число дорог с высотой.

### Что делать после прогона

- Видео MatSim, SUMO и Webots показывают, как машины ездят по графу.
- `pipeline.log`: сколько машин и поездок, приняты ли дополнительные файлы.
- `fcd.xml` загружается обратно в программу кнопкой «Из прогона SUMO...», чтобы получить настоящие потоки и скорости по дорогам.

## Свои теги в .osm

В OSM нет стандартных тегов для этих данных, поэтому редактор хранит их в пространстве `wayfinders:`. Симуляторы такие теги пропускают, а в редакторе они открываются вместе с файлом.

| Тег | Где | Что значит |
|---|---|---|
| `wayfinders:cycle`, `wayfinders:green`, `wayfinders:yellow`, `wayfinders:red` | узел-светофор | время фаз, секунды |
| `wayfinders:green:<подход>`, `wayfinders:yellow:<подход>`, `wayfinders:red:<подход>`, `wayfinders:offset:<подход>` | узел-светофор | свои фазы и сдвиг для каждого подхода |
| `wayfinders:volume` | дорога | интенсивность N, авт/ч (замер) |
| `wayfinders:travel_time` | дорога | фактическое время проезда T факт, мин (замер) |
| `wayfinders:friction` | дорога | свой коэффициент сцепления φ, 0,1-1 |
| `wayfinders:category` | дорога | категория дороги общего пользования IА-V |
| `wayfinders:custom` | маршрут | маршрут создан в редакторе |

Все остальное (полосы, скорость, покрытие, мосты, светофоры, переходы) записывается стандартными тегами OSM.

## Как устроена программа

Технологии: Electron, React, TypeScript, Vite, MapLibre (карта), deck.gl (слои графа), zustand (хранилище), Chart.js (графики), fast-xml-parser (чтение `.osm`), electron-builder (сборка).

Главные решения:

- **Данные в памяти.** Узлы, дороги и отношения OSM лежат в словарях по id. Все, что программа не правит, сохраняется как было.
- **Одна точка правки.** Каждая правка проходит через одну функцию, которая запоминает, какие дороги и узлы менялись. Из этого строятся отмена, журнал и сравнение с исходным файлом.
- **Проверка после каждой правки.** Граф проецируется в метры, близкие узлы ищутся по сетке 40 м, связность считается через объединение множеств и алгоритм Тарьяна.
- **Свое пространство тегов.** Время светофоров и замеры хранятся в тегах `wayfinders:*` прямо в `.osm`, поэтому файл остается один.
- **Два языка.** Интерфейс на русском и английском, переключение в меню.

```
electron/            окно приложения, открытие и сохранение файлов
src/osm/             модель данных, чтение и запись .osm
src/model/           правки и история, проверки, расчеты, сравнение,
                     маршруты, полосы, выгрузка для SUMO и Webots, чтение fcd.xml
src/components/      карта и панели интерфейса
src/guide.ru.ts      встроенное руководство (en - английское)
public/example.osm   пример от организаторов
demo/                граф команды, файлы для сервера, демо с замерами
DESIGN.md            правила оформления интерфейса
CHANGELOG.md         что менялось от версии к версии
```

## Версии

Номер версии из трех чисел, например `0.14.6`. Он виден в верхней панели программы и в заголовке окна. Что менялось от версии к версии, смотрите в [CHANGELOG.md](CHANGELOG.md).

- **Среднее число** растет, когда добавлена заметная пачка функций: `0.13.0` → `0.14.0`.
- **Последнее число** растет, когда были только исправления: `0.14.0` → `0.14.1`.
- **1.0.0** - версия, которую сдаем на хакатоне.

Номер поднимаем сразу в том же изменении, которое приносит обновление.

Как выпустить версию:

1. В [CHANGELOG.md](CHANGELOG.md) перенести пункты из «Следующая версия» в новый раздел с номером и датой.
2. Поднять номер:
   ```bash
   npm version patch --no-git-tag-version
   ```
   Для большого обновления вместо `patch` пишется `minor`.
3. Закоммитить, поставить тег и отправить:
   ```bash
   git tag -a v0.14.6 -m "Версия 0.14.6"
   git push --follow-tags
   ```
4. На GitHub в разделе **Releases** создать выпуск по этому тегу, вставить список изменений и приложить собранный `.exe` из папки `release/`.

## Частые вопросы

- **Картограмма пустая.** Не заданы замеры. Задайте интенсивность N в свойствах дороги или загрузите `fcd.xml` прогона.
- **Город не скачивается.** Серверы OpenStreetMap бывают перегружены, программа сама ждет и повторяет. Попробуйте позже или снимите галочку «Вместе со зданиями».
- **Много изолированных участков по краю карты.** Это дороги, обрезанные краем скачанной области. Их обычно оставляют.
- **Связность ниже 100%.** Чаще всего это односторонние дороги, обрезанные краем карты: въехать можно, выехать некуда. Разворотов на краю мы не придумываем, чтобы не искажать сеть.
- **Не видно полос.** Приблизьте карту и проверьте слой «Полосы и разметка».
- **«Фазы светофоров...» пишет, что светофоров нет.** Нужен `network.net.xml` из `scenario.zip` прогона этого же графа.
- **Загрузка из SUMO маленькая.** В сценарии сервера около 200 поездок за час, поэтому Z низкий. Это свойство сценария, а не ошибка графа.
- **Нужно вернуть как было.** Ctrl+Z отменяет любую правку, включая массовые.
