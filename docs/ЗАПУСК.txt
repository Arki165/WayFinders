WAYFINDER 1.0.0 - редактор графа улично-дорожной сети (команда WayFinders)

КАК ЗАПУСТИТЬ
1. Запустите "Wayfinder 1.0.0.exe" двойным щелчком. Устанавливать ничего не нужно.
2. Если Windows пишет "Система Windows защитила ваш компьютер": нажмите "Подробнее",
   затем "Выполнить в любом случае" (у файла нет платной цифровой подписи).
3. Первый запуск 10-20 секунд: программа распаковывает себя во временную папку.
4. На стартовом экране:
   - "Открыть пример: Иркутск, example.osm" - исходный файл организаторов;
   - "Открыть" - файл из папки demo:
       demo\hack-team3.osm        граф после редактора (отправлен на сервер проверки);
       demo\Wayfinders_demo.osm   тот же участок с замерами для картограммы и расчетов.
5. Руководство и горячие клавиши - меню справа вверху.

MAC (процессор Apple M1-M4)
- Скачать .dmg из Releases на GitHub, открыть, перетащить Wayfinder в "Программы".
- Первый запуск: правой кнопкой по Wayfinder - "Открыть" - "Открыть"
  (файл без подписи Apple). Если пишет "программа повреждена" - в Терминале:
  xattr -cr /Applications/Wayfinder.app

ЧТО НУЖНО
- Windows 10/11, 64 бит, видеокарта с WebGL 2 (если карта не рисуется - обновить драйвер).
- Интернет нужен только для подложки (спутник, схема), рельефа и загрузки района из OSM.
  Без интернета граф открывается, правится, проверяется и сохраняется.

Исходный код: https://github.com/Arki165/WayFinders
